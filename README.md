# Oral Dent — сайт клиники (Next.js + TypeScript + Tailwind)

36 страниц: 4 языка (UZ без префикса, `/ru/`, `/en/`, `/zh/`) × 9 страниц. Все страницы собираются заранее
(статически); на сервере работает только приём заявок `/api/lead/` → Telegram-группа администраторов.

## Что нужно на компьютере (один раз)

1. **Node.js LTS** — https://nodejs.org (кнопка LTS, установить как обычную программу).
   Проверка в терминале VS Code: `node -v` → должно быть v20.9 или новее.
2. Открыть папку проекта в VS Code → Terminal → New Terminal.
3. `npm install` — скачает зависимости (папка `node_modules`, ~300 МБ, в git не попадает).

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | сайт на http://localhost:3000 с автообновлением при правках |
| `npm run build` | производственная сборка (то же делает Vercel) |
| `npm start` | запустить собранный сайт локально |
| `npm run typecheck` / `npm run lint` | проверка типов и кода |
| `npm run check:launch` | что ещё не готово к запуску |

Заявки локально: скопировать `.env.example` в `.env.local` и вписать токен бота и id группы.

## Где что менять

- **Тексты, цены, телефон, часы, отзывы, сертификаты** — `src/content/site.json` (все 4 языка).
  - `settings.url` — адрес сайта после подключения домена (canonical, hreflang, sitemap).
  - `settings.metrika_id` — номер счётчика Яндекс Метрики (пусто = Метрика выключена).
- Фото и видео — `public/img`, `public/media`, `public/brand` (размеры картинок — `src/content/media.json`).
- Дизайн — `src/app/globals.css`: цвета обеих тем (светлой и тёмной) — переменные в блоках `[data-theme="light"]` и `[data-theme="dark"]` в начале файла. Переключатель темы — `src/components/client/Theme.tsx`, анимации прокрутки — `src/components/client/Motion.tsx`.
- Страницы — `src/components/pages/*.tsx`, шапка/подвал — `src/components/Chrome.tsx`.
- Приём заявок — `src/app/api/lead/route.ts`.

## Выкладка на Vercel

1. Загрузить проект в GitHub (репозиторий может быть приватным).
2. vercel.com → Add New → Project → Import этот репозиторий. Framework определится сам (Next.js), ничего не менять.
3. Settings → Environment Variables (Production):
   - `TELEGRAM_BOT_TOKEN` — токен от @BotFather
   - `TELEGRAM_CHAT_ID` — id группы администраторов (отрицательное число, например `-1001234567890`)
   - `NEXT_PUBLIC_SITE_URL` — когда будет домен (необязательно)
4. Deployments → Redeploy (переменные применяются только к новой сборке) → отправить тестовую заявку.
5. Домен: Settings → Domains → добавить домен и прописать DNS-записи, которые покажет Vercel.

**Тариф.** Hobby (бесплатный) по правилам Vercel — только для личных некоммерческих проектов. Сайт клиники —
коммерческий, нужен Pro ($20 за пользователя в месяц). Альтернатива без этого ограничения — Cloudflare
(предыдущая статическая версия сайта была сделана под Cloudflare Pages).

## Как бот попадает в группу

1. @BotFather → `/newbot` → получить токен.
2. Добавить бота в группу администраторов, написать в группу любое сообщение.
3. Открыть `https://api.telegram.org/bot<ТОКЕН>/getUpdates` → `chat.id` группы (с минусом).
   Если группа стала супергруппой, id меняется на `-100…` — брать новый.

## Защита формы

Сервер принимает только запросы со своего домена, до 8 КБ, проверяет имя и телефон, отсекает ботов
(скрытое поле и отправка быстрее 2,5 с). Ничего не хранит: заявка уходит одним сообщением в Telegram.
Без JavaScript форма тоже работает (обычная отправка → страница «Спасибо»).
